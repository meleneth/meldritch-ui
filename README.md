# meldritch-ui

Independent Vue, Phaser, and Pinia frontend for Meldritch. It consumes the
versioned Web protocol generated by `meldritch-contracts`; it has no Rust or
Lua source dependency.

## Development

```sh
npm ci
npm run dev
```

Vite proxies `/api` and `/performance` to `http://127.0.0.1:8080` by default.
Set `VITE_MELDRITCH_ENGINE_URL` to connect directly to another engine. The
engine must allow the development origin when the browser crosses origins.

`npm run check` validates the pinned generated contract, typechecks, runs the
fixture-backed tests, checks formatting, and builds `dist/`. No Cargo checkout
or build is involved. A production engine serves that directory through its
configured `MELDRITCH_UI_DIST` path.

## Contract updates

`contracts.lock` pins an immutable `meldritch-contracts` revision and artifact
digest. Update `src/generated/protocol.ts` only by copying it from that exact
contract release, then run `npm run check`. Presentation models in
`src/types/protocol.ts` may add ephemeral UI state, but wire messages must come
from the generated module.

State is accepted only in increasing revision order within one engine epoch.
An epoch change discards prior optimistic state. Every connection negotiates
the protocol before authentication, then converges on authoritative snapshots
and full-value updates.
